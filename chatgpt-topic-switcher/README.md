# ChatGPT Topic Switcher

一个 Chrome Manifest V3 扩展：根据最近对话关键词，提示你可能已经切换主题。

## 功能

- 监听 ChatGPT 输入框（支持 textarea 与 contenteditable）
- 记录当前页面最近对话关键词
- 对中英文关键词做轻量相似度判断
- 主题变化明显时弹出选择框
- 继续当前对话，或打开新 ChatGPT 标签页
- 可将最近对话摘录填入新标签页草稿
- 点击扩展弹窗可清除当前主题记录

## 安装

1. 打开 Chrome，访问 `chrome://extensions/`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本项目文件夹。
5. 打开或刷新 ChatGPT 页面。

## 测试

先讨论一个主题，再发送明显无关的问题。相似度低于 18% 时会出现提示。

## 限制

这是关键词启发式检测，不是 AI 语义判断；ChatGPT 页面结构变化后，选择器可能需要更新；自动填充依赖页面完成加载，最终发送仍由你确认。
